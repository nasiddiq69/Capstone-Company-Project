# Requirements and decisions log

Use this document to record decisions with the mentor/team. Do not treat the starter feature list as final requirements.

## Questions to confirm
- Who will use the system (students, employees, administrators)?
- What can be reserved (meeting rooms, desks, equipment)?
- What information is required to make a reservation?
- Are there limits on reservation duration or advance booking?
- How should cancellations and changes work?
- Which database will be used?
- Will the project have a web UI, desktop UI, or command-line interface?
- Is machine learning actually required? If yes, what problem will it solve?
- What are the expected deliverables and evaluation criteria?
